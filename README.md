# Unconference Sessions Scheduler

**Un**conference **Se**ssion **Sch**eduler is an application that enables displaying and managing
sessions in an Open Space, Bar Camp or Un-Conference.

The application has a public view, that can be accessed without authentication to:

* View scheduled sessions and their details.
* Create and view a customized schedule of selected sessions.
* Share a customized schedule.

Authenticated operators manage the schedule by:

* Creating rooms.
* Creating sessions.
* Assigning sessions to rooms.
* Adding new operators accounts.
